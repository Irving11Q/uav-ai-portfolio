# 服装洗护指南

适用范围：本指南适用于本店在售服装类商品的日常清洗、晾晒、熨烫、收纳及污渍处理，用于回答顾客关于「怎么洗」「能不能机洗」「缩水怎么办」等洗护类咨询。

## 一、看懂水洗标（洗护标签符号对照）

购买后请**先看衣服内侧的水洗标**，它是该件衣服唯一权威的洗护依据。本店商品水洗标符号含义如下：

| 符号 | 含义 | 说明 |
|---|---|---|
| 水盆 + 数字 30/40/60 | 最高洗涤水温 | 数字即水温上限（℃），未标数字通常为 30℃ 以下 |
| 水盆 + 一只手 | 手洗 | 最高 40℃，禁止机洗 |
| 水盆 + 一条横线 | 缓和洗涤 | 轻柔程序、减少时间 |
| 水盆 + 叉号 | 禁止水洗 | 只能干洗 |
| 三角形 | 漂白 | 空格为可漂白，带叉为禁止漂白 |
| 正方形 + 圆圈 | 可烘干 | 圆圈内点数表示温度，点越多温度越高 |
| 正方形 + 竖线 | 悬挂晾干 | 避免暴晒 |
| 正方形 + 横线 | 平摊晾干 | 针织、羊毛类必须平铺 |
| 熨斗 + 点 | 熨烫温度 | 1 点 = 110℃（化纤），2 点 = 150℃（羊毛），3 点 = 200℃（棉麻） |
| 圆圈 + P / F | 干洗 | P 为常规干洗，F 为石油溶剂干洗 |
| 圆圈 + 叉号 | 禁止干洗 | — |

> 顺口溜：**水盆看温度，三角管漂白，方块管晾干，熨斗看点，圆圈管干洗。**

## 二、常见面料洗护要点

| 面料 | 洗涤方式 | 水温 | 晾晒 | 禁忌 |
|---|---|---|---|---|
| 纯棉 | 机洗/手洗均可 | ≤40℃ | 阴凉通风或翻转晾晒 | 忌长时间暴晒（易泛黄变硬）、忌高温烘干（缩水） |
| 亚麻 | 手洗或轻柔机洗 | ≤30℃ | 阴干、半干时熨烫 | 忌用力拧干、忌漂白 |
| 真丝 | 手洗（中性洗涤剂） | ≤30℃ 冷水 | 阴凉处平铺或挂晾 | 忌碱性洗衣粉、忌拧绞、忌暴晒、忌机洗 |
| 羊毛/羊绒 | 手洗或羊毛程序 | ≤30℃ 冷水 | **平铺阴干** | 忌揉搓、忌拧干、忌悬挂（会拉长变形）、忌热水 |
| 涤纶 | 机洗 | ≤40℃ | 正常晾晒 | 忌高温熨烫（会熔融发亮） |
| 锦纶 | 机洗 | ≤40℃ | 阴干 | 忌暴晒（易发黄变脆） |
| 氨纶 | 随主体面料 | ≤30℃ | 阴干 | 忌高温、忌漂白（会失去弹性） |
| 腈纶 | 机洗轻柔 | ≤30℃ | 平铺晾干 | 忌高温、忌用力搓 |
| 粘胶/莫代尔/天丝 | 手洗或轻柔机洗 | ≤30℃ | 平铺晾干 | 忌拧绞、忌浸泡过久、湿态强度低易破 |
| 牛仔布 | 反面机洗 | ≤30℃ | 反面阴干 | 首次单独洗（掉色）、忌暴晒 |
| 羽绒服 | 机洗（羽绒程序）或手洗 | ≤30℃ | 平铺晾干 + 拍打 | 忌干洗（伤羽绒）、忌拧干、忌暴晒 |
| 皮革/PU | 湿布擦拭 | — | 阴凉通风 | 忌水洗、忌暴晒、忌折叠压 |
| 毛呢/大衣 | 干洗为主 | — | 悬挂通风 | 忌水洗（易缩绒变形）、忌刷毛 |

## 三、洗涤前必做的分类

1. **按颜色分**：白色、浅色、深色、易掉色（牛仔、深红、亮蓝）分开洗，新深色衣物建议单独洗 2-3 次。
2. **按材质分**：厚重（牛仔、卫衣、毛巾）与轻薄（真丝、针织、蕾丝）分开，避免摩擦起球。
3. **按脏污程度分**：重度脏污与轻度穿着过的衣物分开，避免交叉污染。
4. **按贴身程度分**：内衣、袜子单独洗，建议使用洗衣袋。
5. **清空口袋 + 拉好拉链 + 扣好纽扣 + 反面朝外**，防止染色、勾丝与拉链刮伤其他衣物。

## 四、洗涤剂与水温选择

| 场景 | 推荐洗涤剂 | 水温 |
|---|---|---|
| 棉麻常规洗 | 普通洗衣液 | 30-40℃ |
| 真丝/羊毛/羊绒 | 中性丝毛专用洗涤剂 | 20-30℃ 冷水 |
| 婴幼儿衣物、内衣 | 中性温和洗衣液，无荧光剂 | 30-40℃ |
| 汗渍、油渍较重 | 含酶洗衣液 | 40℃ 以下（超 40℃ 酶失活） |
| 白色棉织物 | 含氧漂白剂（彩漂） | 40-60℃ |
| 顽固异味 | 含氧漂白剂浸泡 | 按产品说明 |

**注意事项**
- 洗涤剂先用水化开再放入衣物，直接倒在衣服上易造成局部褪色。
- **含氯漂白剂（84 等）会损伤纤维并导致发黄**，除非水洗标明确允许，否则禁止使用。
- 柔顺剂会降低毛巾、浴巾吸水性，也会削弱运动服排汗功能，这类单品不建议使用。

## 五、手洗与机洗操作要点

**手洗标准流程**
1. 水温调至 30℃ 以下，洗涤剂完全溶解。
2. 浸泡 5-10 分钟（真丝、羊毛不超过 5 分钟）。
3. **按压式揉洗**，不要搓、不要拧；领口袖口可局部轻搓。
4. 用同温水漂洗 2-3 次，直至无泡沫。
5. 真丝、羊毛类最后一遍漂洗可加少量护发素或柔顺剂改善手感。
6. **挤干而非拧干**：用干毛巾包裹卷压吸水，再平铺晾干。

**机洗推荐设置**
- 常规衣物：标准程序、40℃、转速 800 转以内。
- 轻薄/针织/带装饰款：轻柔程序、30℃、装入洗衣袋。
- 羽绒服：羽绒专用程序，转速 600 转以内，可加网球帮助拍散。
- 洗涤量不要超过内筒 2/3，过满洗不净、过少易磨损。

## 六、晾晒与烘干

| 面料/单品 | 晾晒方式 | 是否可烘干 |
|---|---|---|
| 棉T恤、家居服 | 反面挂晾 | 可低温烘干 |
| 衬衫 | 挂晾，趁半干整形 | 可低温烘干后立即挂起 |
| 针织衫、羊毛衫 | **平铺阴干** | 不建议 |
| 真丝 | 反面阴干 | 不可 |
| 牛仔裤 | 反面阴干 | 不建议 |
| 羽绒服 | 平铺晾干并拍打复蓬 | 可低温烘干 + 网球 |
| 内衣 | 阴干，罩杯朝上或夹侧边 | 不可（高温伤弹力） |
| 毛呢大衣 | 悬挂通风 | 不可 |

**通用规则**
- **暴晒会伤一切面料**：紫外线导致褪色、泛黄、纤维脆化。除白色棉织物可适度日晒外，其余一律阴干。
- 深色衣物**反面朝外**晾晒，减少褪色。
- 潮湿天气可用烘干机或除湿机辅助，避免久湿发霉。
- 晾干后及时收纳，长时间悬挂晾晒会造成肩部变形（针织类尤其明显）。

## 七、熨烫温度对照

| 面料 | 熨烫温度 | 方式 |
|---|---|---|
| 涤纶、锦纶、腈纶 | 110℃ 以下 | 垫布或反面熨烫 |
| 羊毛、羊绒 | 150℃ 以下 | 垫湿布，蒸汽熨烫 |
| 棉、麻 | 200℃ 以下 | 半干时熨烫效果最佳 |
| 真丝 | 110-150℃ | **反面、垫布、低温**，禁喷水直烫 |
| 粘胶/莫代尔 | 110℃ 以下 | 干熨，避免拉长 |
| 带印花/烫钻/涂层 | 60-80℃ 或禁止熨烫 | 避开图案区域 |

> 没有温度档位时，从最低温开始试，先在衣角或内侧不显眼处试烫。

## 八、收纳与保养

- **换季收纳前必须洗净**：残留汗渍、污渍在长期存放后会氧化发黄、招虫。
- 折叠存放优于悬挂（针织、羊绒必须折叠），衣架选择宽肩型避免肩部鼓包。
- 羊毛、羊绒、真丝类可放**防蛀香草包或樟脑丸（用纸包好，勿直接接触衣物）**。
- 保持衣柜干燥通风，湿度高时使用除湿剂；雨季结束后开柜通风。
- 真皮单品需用专用保养油定期护理，避免受潮发霉，存放时塞入支撑物保持形状。
- 白色衣物单独存放，可用无酸纸包裹或棉布袋，避免与深色接触泛黄。

## 九、常见污渍处理方法

| 污渍类型 | 处理方式 | 注意 |
|---|---|---|
| 油渍（食用油、酱汁） | 干衣状态涂洗洁精，静置 5-10 分钟后温水洗 | 不要先沾水，先沾水会固定油渍 |
| 血渍 | **冷水**加肥皂或含酶洗涤剂轻搓 | 绝对不能用热水，会使蛋白凝固 |
| 咖啡/茶渍 | 立即用冷水冲，再以含氧漂白剂浸泡 | 陈旧渍需延长浸泡时间 |
| 红酒渍 | 立即吸干（勿擦），撒盐或苏打粉吸色，再用冷水冲洗 | 越早处理越好 |
| 墨水渍 | 用酒精或牛奶轻搓，再常规洗涤 | 先在隐蔽处测试是否褪色 |
| 圆珠笔印 | 酒精棉球轻擦 | 真丝、醋酸面料慎用酒精 |
| 口香糖 | 冰块冷冻后剥离，残留用酒精擦拭 | 勿硬撕，会拉坏纤维 |
| 汗渍（腋下泛黄） | 白醋+小苏打糊敷 30 分钟后洗涤 | 陈旧黄渍可用含氧漂白剂浸泡过夜 |
| 霉斑 | 含氧漂白剂浸泡，或用淡醋水擦拭后洗净 | 含氯漂白会留黄斑，慎用 |
| 口红/化妆品 | 卸妆油或洗洁精预处理后洗涤 | 避开真丝、皮革 |
| 铁锈 | 草酸溶液或专用除锈剂处理 | 处理后彻底漂洗 |
| 泥渍 | **晾干后刷掉**再洗 | 湿态搓洗会把泥揉进纤维 |

**污渍处理铁律**：① 越早越好；② 从污渍外缘向中心处理；③ 先在不显眼处测试；④ 不要用热水处理蛋白类污渍（血、奶、蛋）；⑤ 不要用吹风机或熨斗直接加热未处理的污渍。

## 十、常见洗护错误与禁忌

| 错误做法 | 后果 | 正确做法 |
|---|---|---|
| 羊毛衫热水洗、用力搓 | 缩水、毡化、变形 | 30℃ 以下冷水按压洗，平铺阴干 |
| 真丝用普通洗衣粉 | 泛白、失去光泽、发脆 | 中性丝毛专用洗涤剂，冷水轻洗 |
| 深色新衣与浅色同洗 | 染色，浅色报废 | 分类洗，新深色前几次单独洗 |
| 血渍用热水 | 污渍永久固定 | 冷水处理 |
| 针织衫悬挂晾晒 | 拉长变形、肩部鼓包 | 平铺阴干 |
| 羽绒服干洗 | 羽绒脱脂、保暖性下降 | 水洗羽绒模式 + 拍打复蓬 |
| 高温烘干棉/羊毛 | 缩水、手感变硬 | 低温或自然晾干 |
| 长期暴晒 | 褪色、泛黄、纤维脆化 | 阴凉通风处阴干 |
| 洗衣液直接倒衣服上 | 局部褪色斑点 | 先溶解再放衣物 |
| 洗涤剂用量越多越好 | 残留导致皮肤瘙痒、面料发硬 | 按说明用量，必要时增加漂洗次数 |
| 脏衣服长期堆放不洗 | 污渍氧化难除、发霉生虫 | 及时清洗，勿超过 3-5 天 |
| 不洗就收纳换季衣物 | 虫蛀、发黄、霉斑 | 洗净彻底晾干后收纳 |

## 十一、重点单品护理速查

| 单品 | 一句话要点 |
|---|---|
| 白衬衫 | 领口袖口用洗洁精或衣领净预处理，忌含氯漂白，阴干避免泛黄 |
| 羊毛衫 | 冷水按压洗，毛巾吸水，平铺阴干，折叠收纳 |
| 真丝衬衫 | 冷水手洗、中性洗涤剂、反面低温熨烫、避光存放 |
| 牛仔裤 | 反面洗、少洗（穿 3-5 次洗一次）、反面阴干、首次单独洗 |
| 羽绒服 | 30℃ 水洗、勿拧、平铺晾干、拍打复蓬，勿干洗 |
| 卫衣 | 反面洗、勿高温烘干、印花部位勿熨烫 |
| 内衣 | 手洗或洗衣袋机洗、勿拧罩杯、阴干、勿高温 |
| 运动服 | 勿用柔顺剂（堵塞排汗纤维）、及时洗、阴干 |

## 十二、洗护常见问题（FAQ）

**问：标签写着可以机洗，但我想手洗，可以吗？**
答：可以。手洗比机洗更温和（除羽绒服外）。注意控制水温不超过标签标注温度，并避免拧绞。

**问：衣服洗后缩水了怎么办？**
答：棉、羊毛类轻微缩水可在半干状态下轻柔拉伸整形后平铺晾干；缩水超过 5% 通常无法恢复，属面料正常特性。后续洗涤建议降低水温、缩短时间。

**问：会掉色的深色衣服怎么洗？**
答：首次洗加一勺盐或白醋固色（仅适用棉麻深色，真丝慎用醋），单独冷水洗，反面阴干。掉色属正常染整现象，一般 3-5 次后稳定。

**问：衣服有异味但没脏，必须洗吗？**
答：可挂通风处晾 1-2 天，或用蒸汽挂烫机处理。若为汗味残留，需水洗，光通风无法去除。

**问：羊毛衫起球是质量问题吗？**
答：不是。羊毛、羊绒、混纺类天然纤维在摩擦处起球属正常现象，可用毛球修剪器或剃须刀轻刮处理，勿用力拉扯。

**问：新买的衣服要先洗再穿吗？**
答：建议先洗。生产、运输、试穿过程中可能残留浮色、助剂与灰尘，贴身衣物尤其建议清洗后再穿。

**问：可以用柔顺剂吗？**
答：棉麻类可使用，但毛巾、浴巾、运动服、速干衣不建议（影响吸水与排汗）。真丝、羽绒服不宜使用。

**问：干洗和在家洗怎么选？**
答：西装、毛呢大衣、真丝礼服、带复杂装饰的单品建议干洗；日常棉T恤、卫衣、运动服、内衣均可在家庭洗护。羽绒服则相反，**建议水洗而非干洗**。

**问：衣服发霉了还能穿吗？**
答：可先用含氧漂白剂浸泡并彻底清洗、晾晒后观察；若霉斑深入纤维、出现明显斑点或异味残留，建议停止使用，避免皮肤刺激。

**问：多久洗一次合适？**
答：贴身衣物（内衣、T恤、袜子）每次穿着后清洗；衬衫 1-2 次；卫衣、针织衫 3-5 次；牛仔裤 3-5 次；外套、毛呢大衣视穿着环境，一季 2-3 次即可。
