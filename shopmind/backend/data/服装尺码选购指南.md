# 服装尺码选购指南

适用范围：本指南适用于本店在售的男女装、童装、裤装、内衣及鞋类商品，用于帮助顾客根据自身体型数据选择正确尺码，降低因尺码不合导致的退换货。

## 一、选购前必须做的三件事

1. **先量体，再选码。** 不要凭平时穿的码数直接下单，不同品牌、不同版型的同码差异可达 1-2 个号。
2. **量体穿贴身衣物**，软尺贴合身体但不勒紧，保持自然站姿、正常呼吸，不要刻意收腹或挺胸。
3. **优先看商品详情页的「实际测量尺寸表」**，而不是只看 S/M/L 标签。标签只是代号，厘米数才是事实。

## 二、身体尺寸测量方法

| 测量部位 | 测量方法 | 要点 |
|---|---|---|
| 胸围 | 绕胸部最丰满处水平一周 | 软尺保持水平，不勒紧，手臂自然下垂 |
| 下胸围 | 绕乳房下缘水平一周 | 决定内衣罩杯的基础尺码 |
| 腰围 | 绕腰部最细处一周 | 通常在肚脐上方 2-3cm，不要收腹 |
| 臀围 | 绕臀部最丰满处水平一周 | 双脚并拢，软尺水平 |
| 肩宽 | 从左肩骨点量到右肩骨点 | 后背测量更准，是判断上衣是否合身的关键 |
| 衣长 | 从肩颈点垂直到下摆 | 与身高、上身比例相关 |
| 袖长 | 从肩骨点沿手臂外侧量到手腕 | 长袖商品重点看此项 |
| 大腿围 | 绕大腿最粗处一周 | 选紧身裤、修身裤必量 |
| 裤长 | 从腰侧骨点量到脚踝或所需位置 | 与身高直接相关 |
| 脚长 | 脚跟到最长脚趾的距离 | 建议下午或傍晚测量，脚部会略微膨胀 |

**测量小贴士**
- 自己量胸围、臀围容易有误差，建议请他人协助，或对着镜子确认软尺水平。
- 左右身体通常不完全对称，肩宽、袖长以较长一侧或常用手一侧为准。
- 两次测量结果取平均值，误差控制在 1cm 以内再使用。

**牛仔裤与休闲裤选码差异**
- 牛仔裤：无弹或微弹面料，量出腰围后**建议选大一码**，腰头松一点可搭皮带。
- 弹力休闲裤、运动裤：含氨纶 3% 以上，通常**按实际腰围选或选小一码**，穿着会自然贴合。
- 直筒裤与锥形裤：腰围相同的情况下，锥形裤大腿围更紧，腿粗人群建议上浮一码。

**鞋类选码建议**
- 运动鞋、跑鞋：脚趾前需留 **1-1.5cm** 活动空间，建议按脚长对应码数**选大 0.5-1 码**。
- 皮鞋、单鞋：真皮会随穿着略微撑开，**按实际脚长选**，不要贪大。
- 靴子：需搭配厚袜，建议**上浮 1 码**。
- 脚宽/脚背高：优先选宽楦（2E/4E）或圆头鞋款，必要时上浮半码。

## 八、按体型选购建议

| 体型特征 | 选码策略 | 版型建议 |
|---|---|---|
| 偏瘦（BMI < 18.5） | 按实际测量尺码选，避免过大 | 可选修身、直筒版型，避免过度 Oversize 显得垮 |
| 标准（18.5 ≤ BMI < 24） | 按对照表正常选码 | 版型限制最小，按喜好选择 |
| 微胖（24 ≤ BMI < 28） | 胸围/腰围取上限，肩宽合身优先 | 选宽松版、微廓形；避开紧身弹力面料 |
| 偏胖（BMI ≥ 28） | 按主要围度（胸围或臀围）以最大值选码 | 选直筒、A 字版型，深色显瘦；避免横条纹紧身款 |
| 梨形身材 | 以臀围为主要依据，腰围可后缝收 | 选 A 字裙、阔腿裤，上紧下松 |
| 苹果形身材 | 以胸围/上腹围为主要依据 | 选高腰直筒、帝国腰线，避开低腰紧身 |
| 高个子（女 > 170cm / 男 > 185cm） | 重点核对衣长、袖长、裤长 | 选修长版、加长款，避免九分裤 |
| 娇小（女 < 155cm） | 重点看衣长与裤长，宁短不长 | 选短款上衣、九分裤，高腰线 |
| 孕妇 | 按孕前尺码 +1 至 +2 码，或直接选孕妇线 | 选弹力腰头、抽绳设计，避免收腰显怀款 |

## 九、不同品类的选码技巧

| 品类 | 关键维度 | 选码建议 |
|---|---|---|
| T恤/卫衣 | 胸围、肩宽 | 常规版按胸围选，Oversize 款可小一码 |
| 衬衫 | 胸围、肩宽、领围 | 商务款大一码；休闲款正常选 |
| 西装外套 | 肩宽、胸围、袖长 | 肩宽必须完全合身，胸围留 8-10cm 活动量 |
| 连衣裙 | 胸围、腰围、臀围 | 收腰款以腰围为准；A 字款以胸围为准 |
| 牛仔裤 | 腰围、臀围、大腿围 | 一般大一码；腿粗以大腿围为准 |
| 西装裤 | 腰围、裤长 | 腰围可略大（可改），裤长宁长不短（可改短） |
| 内衣 | 下胸围 + 罩杯 | 下胸围决定底围数字，上下胸围差决定罩杯 |
| 外套/羽绒服 | 胸围、衣长 | 内搭厚衣时需上浮 1-2 码 |

## 十、尺码选购常见问题（FAQ）

**问：平时穿 M 码，是不是直接选 M 就行？**
答：不一定。不同品牌版型差异明显，同码胸围可能相差 4-6cm。请以商品详情页的实际测量厘米数为准，与自己的测量数据比对后再决定。

**问：衣服买回来偏小，能换吗？**
答：支持 7 天无理由退换（吊牌未拆、不影响二次销售）。换码时请按退回尺码重新测量比对，避免再次换错。

**问：不确定选哪个码怎么办？**
答：优先选择「偏大一码」——因为可改小、可搭内搭，而偏小基本无法挽救。也可联系客服提供身高体重和胸腰臀数据，由客服协助推荐。

**问：洗后会缩水吗？需要提前买大吗？**
答：纯棉、亚麻、粘胶类面料水洗后常见 2%-5% 缩水，若商品标明「未预缩」，建议按需**上浮一码**。聚酯纤维、锦纶等化纤面料基本不缩水。

**问：线上线下尺码一样吗？**
答：同一品牌通常一致，但仍建议以线上详情页测量表为准，因为不同批次、不同生产线可能有细微差异。

**问：欧美品牌和国际码怎么选？**
答：欧美版型普遍肩宽、袖长、衣长更长。亚洲女性选欧美品牌时，胸围合身的情况下常需**关注腰围偏大**的问题，必要时上浮半码或选择修身系列。

**问：孩子长得快，童装是不是该买大点？**
答：可上浮一码预留生长空间，但不建议上浮两码以上，过大影响穿着安全（尤其幼童）与活动灵活性。

**问：买大了可以怎么处理？**
答：可联系客服改小（部分品类支持）、搭配厚内搭、或作为宽松版穿着。建议下单前务必核对尺码，避免依赖事后修改。
