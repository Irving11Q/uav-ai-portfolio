# W1: Getting Started with PySide6 (PC-side GUI)

Code produced in Week 1 of the "UAV AI Application Development" 8-week plan. Learning the basics of desktop (host/PC-side) GUI development with PySide6: widgets, layouts, and signals/slots.

## Files

| File | Description |
|---|---|
| `day1_controls.py` | Demo of common widgets and layout nesting: QLabel, QLineEdit, QComboBox, QCheckBox, QTableWidget, VBox/HBox layouts, and signal-slot connections |

## Requirements

- Python 3.12
- PySide6 >= 6.0

Install dependencies:

```bash
pip install PySide6
```

## Run

```bash
python day3_controls.py
```

A window will open where you can try each widget: type in the input box, pick an option from the combo box, toggle the checkbox, and click the buttons to see the label update.
